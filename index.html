OxtanDB v3 is live

A Secure Database Wrapper & CLI.

Oxtan eliminates repetitive boilerplate. It provides a fluent, developer-friendly API that handles connection pooling, prevents SQL injection, and manages profiles via terminal.

Get Started Documentation
$ python main.py --help

Engineered for Python Developers

Manage your database connections from the CLI and query securely from your code.

Zero Boilerplate

Perform standard CRUD operations with single-line methods. Focus on your logic, not the connection strings.

Security First

100% protection against SQL injection using enforced parameterized queries out of the box.

CLI Architecture

Manage connection profiles, view schemas, and query tables directly from your terminal using the modular CLI.

Powerful Terminal Tools

Oxtan provides a scalable command line interface. Manage multiple database profiles locally and switch between them instantly.

  • python main.py add-db
  • python main.py tables
  • python main.py count <table>

$ python main.py use prod_db

> Profile 'prod_db' is now active.

$ python main.py tables

users

transactions

audit_logs

$ python main.py count users

> 1,402,993 rows
