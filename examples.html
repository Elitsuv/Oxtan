Real-World Examples

See how Oxtan's CLI and wrapper handle your data operations seamlessly.

1. Multi-Database Management via CLI

Managing multiple environments (dev, staging, prod) usually means modifying `.env` files manually. Oxtan allows you to save profiles locally and swap them instantly. 

# Add production credentials
$ python main.py add-db
Profile Name: prod_db
Host: 10.0.0.5
...

# Switch to production instantly
$ python main.py use prod_db
> Profile 'prod_db' is now active.

# See all tables in the active profile
$ python main.py tables

2. Exporting directly to Pandas

Instead of fetching rows, converting them to lists, and initializing a DataFrame manually, Oxtan provides a native get_df method to pull results straight into Pandas for analysis. 

from core.db_operations import OxtanDB

with OxtanDB() as db:
    # Returns a pandas.DataFrame instantly
    df = db.get_df("user_analytics", event_type="login")
    
    # Ready for immediate analysis
    print(df.describe())

3. Zero-Boilerplate Operations

You don't need to write raw SQL strings or deal with `%s` parameters for standard operations. Oxtan accepts dictionaries and securely compiles parameterized queries behind the scenes. 

from core.db_operations import OxtanDB

with OxtanDB() as db:
    # Secure INSERT
    db.insert("api_keys", {
        "key_value": "sk_test_123",
        "owner_id": 99,
        "status": "active"
    })

    # Secure UPDATE
    db.update("api_keys", {"status": "revoked"}, owner_id=99)
