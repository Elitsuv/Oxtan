Everything you need to build and scale your data applications with OxtanDB v3.

Introduction

OxtanDB is a utility designed to eliminate the repetitive boilerplate code associated with database connections. It provides a fluent, developer-friendly API that handles connection pooling, prevents SQL injection, and returns data as clean Python dictionaries or Pandas DataFrames.

Version 3 introduces a scalable CLI architecture to manage your databases directly from the terminal!

Installation & Setup

Clone the repository to get started with the CLI tool.

git clone https://github.com/elitsuv/oxtan.git
cd oxtan
python main.py --help

Architecture Overview

Oxtan v3 is designed as a maintainable, scalable CLI application and Python wrapper.

  • cli/: Core command registry and argument parsing.
  • commands/: Individual command implementations (e.g., add-db, use).
  • database/: Connection management and pooling logic.
  • core/: Business logic for database CRUD operations (OxtanDB class).
  • config/: Profile management for storing database connections.

CLI Usage

You can run the Oxtan CLI from the project root. The CommandRegistry parses your input and routes it to the corresponding command module.

python main.py add-db    # Add a new connection profile
python main.py use       # Set the active database profile
python main.py dbs       # List all saved database profiles
python main.py tables    # List all tables in active DB
python main.py schema    # Show schema for a specific table
python main.py peek      # Peek at the first few rows
python main.py count     # Count the number of rows

Database Operations

You can also use the OxtanDB core class directly in your Python scripts for zero boilerplate queries with 100% protection against SQL injection.

Reading & DataFrames

Access your data naturally via column names or directly export it to DataFrames.

from core.db_operations import OxtanDB

with OxtanDB() as db:
    # Native dictionary rows
    users = db.get("users", limit=10)
    
    # Or as a DataFrame directly
    df = db.get_df("users", status="active")
